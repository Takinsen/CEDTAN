## วิชานี้เรียนอะไร

ประมวลรายวิชาเขียนขอบเขตเนื้อหาไว้เป็นภาษาไทยว่า

> หลักการของความมั่นคงของคอมพิวเตอร์ วิทยาการเข้ารหัสลับแบบกุญแจสมมาตร วิทยาการเข้ารหัสลับแบบกุญแจสาธารณะ การย่อยสาร การพิสูจน์ตัวจริง การควบคุมการเข้าถึง ความมั่นคงของวิสาหกิจ ความมั่นคงของเครือข่าย

และเขียนกำกับเป็นภาษาอังกฤษไว้ว่า

> Computer security principles; symmetric key cryptographyl; public key crytography; message digest; authentication: access control; enterprise security; network security.

แตกเป็นรายหัวข้อได้แปดเรื่อง

| หัวข้อ | ภาษาอังกฤษในประมวลรายวิชา |
| --- | --- |
| หลักการของความมั่นคงของคอมพิวเตอร์ | Computer security principles |
| วิทยาการเข้ารหัสลับแบบกุญแจสมมาตร | Symmetric key cryptography |
| วิทยาการเข้ารหัสลับแบบกุญแจสาธารณะ | Public key cryptography |
| การย่อยสาร | Message digest |
| การพิสูจน์ตัวจริง | Authentication |
| การควบคุมการเข้าถึง | Access control |
| ความมั่นคงของวิสาหกิจ | Enterprise security |
| ความมั่นคงของเครือข่าย | Network security |

<Callout type="warn" title="คำสะกดผิดในเอกสารต้นทาง">
ประมวลรายวิชาสะกดคำภาษาอังกฤษไว้ว่า `cryptographyl` และ `crytography` หน้านี้ยกข้อความมาตามต้นฉบับในกล่องคำพูดข้างบน แต่ในตารางเขียนคำที่ถูกต้องคือ *cryptography* ให้
</Callout>

## วัตถุประสงค์ของวิชา

ประมวลรายวิชาเขียนผลลัพธ์การเรียนรู้ (Course Learning Outcome) ไว้ห้าข้อ

1. อธิบายความสำคัญของความมั่นคงของระบบคอมพิวเตอร์
2. นำความรู้ด้านความมั่นคงมาประยุกต์ใช้ในชีวิตประจำวันได้
3. เข้าใจและสามารถประเมินความเสี่ยงหรือผลกระทบจากปัญหาความมั่นคงของระบบคอมพิวเตอร์ได้
4. สามารถศึกษาและเรียนรู้ปัญหาด้านความมั่นคงได้ด้วยตนเอง
5. รู้จักป้องกันตัวเองจากสถานการณ์ที่เกี่ยวข้องกับข้อมูลส่วนบุคคล

<Why>
สังเกตว่าข้อ 2 ข้อ 4 และข้อ 5 ไม่ได้พูดถึงการเขียนโปรแกรมหรือทฤษฎีเลย แต่พูดถึงการเอาไปใช้กับชีวิตตัวเอง

นี่ตรงกับวิธีสอนในสไลด์ ที่เริ่มจากการชวนดูตู้ ATM และตู้นิรภัยของธนาคาร ก่อนจะตั้งชื่อองค์ประกอบว่า Authentication, Authorization และ Accounting
</Why>
