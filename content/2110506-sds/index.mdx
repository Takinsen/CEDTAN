## วิชานี้เรียนอะไร

ประมวลรายวิชาระบุขอบเขตเนื้อหาไว้ 7 เรื่อง

- Software-defined architectures
- Software-defined servers
- Software-defined networks
- Software-defined storage
- Cloud and edge computing architectures
- Containers and service orchestration technology
- Infrastructure as code

สไลด์ Administrivia วางกรอบของวิชาไว้ด้วยคำสี่คำ คือ Compute (Containers), Orchestration, Compute/Storage Resources (Cloud) และ Networks/Connectivity

<Analogy>
สมัยก่อน ถ้าจะเพิ่มเซิร์ฟเวอร์หนึ่งเครื่อง ต้องซื้อเครื่องจริง ยกไปวางในห้องเครื่อง เสียบสายไฟ เสียบสาย network แล้วตั้งค่าทีละอย่างด้วยมือ คำว่า software-defined คือการย้ายงานพวกนี้ไปอยู่ในไฟล์และคำสั่ง แล้วให้ซอฟต์แวร์ไปจัดการเครื่องกับสายให้แทน เหมือนเปลี่ยนจากการเดินไปสับรางรถไฟทีละราง มาเป็นการเขียนตารางเดินรถแล้วให้ระบบสับรางให้เอง
</Analogy>

## วัตถุประสงค์ของวิชา

ประมวลรายวิชาเขียนวัตถุประสงค์ไว้ 3 ข้อ และสไลด์ Administrivia เขียนกำกับแต่ละข้อเป็นภาษาอังกฤษไว้ด้วย

1. อธิบายความหมายของระบบที่กำหนดโดยซอฟต์แวร์ได้ — *What are software-defined systems*
2. ใช้งานระบบที่กำหนดโดยซอฟต์แวร์ได้ — *Use SDS*
3. ออกแบบและจัดการระบบที่กำหนดโดยซอฟต์แวร์ได้ — *Design and manage SDS*

## ศัพท์ที่จะเจอในตารางเรียน

<Why>
ระบบสมัยนี้ไม่ได้มีโปรแกรมเดียวรันอยู่บนเครื่องเดียว แต่มีบริการหลายตัวกระจายอยู่บนเครื่องหลายเครื่อง ถ้าติดตั้งและตั้งค่าด้วยมือทีละเครื่อง จะช้า ผิดพลาดง่าย และสร้างของเดิมขึ้นมาใหม่ให้เหมือนเดิมไม่ได้ สามคำแรกในรายการนี้คือเครื่องมือที่แก้ปัญหานี้คนละส่วนกัน
</Why>

- <Term en="Container" th="กล่องที่ห่อโปรแกรมกับของที่โปรแกรมต้องใช้ไว้ด้วยกัน" /> — แก้ปัญหาโปรแกรมที่รันได้บนเครื่องเรา แต่ไปพังบนเครื่องอื่นเพราะของที่ติดตั้งไว้ไม่เหมือนกัน — สัปดาห์ 2-3
- <Term en="Microservices" th="การแตกระบบใหญ่เป็นบริการเล็ก ๆ หลายตัว" /> — สัปดาห์ 4

## ข้อตกลงในการเรียน

ประมวลรายวิชาและสไลด์ Administrivia เขียนข้อตกลงไว้ตรงกัน 5 ข้อ

1. วิชานี้สอนแบบ on-site นิสิตต้องเข้าเรียนทุกครั้ง มีการเช็คชื่อแบบสุ่มวัน โดยคะแนนเช็คชื่อถือเป็นส่วนหนึ่งของคะแนน activity
2. การจัดสอบมีทั้งหมด 2 ครั้ง เป็นแบบ on-site นิสิตต้องมาสอบที่มหาวิทยาลัยและปฏิบัติตามประกาศจุฬาลงกรณ์มหาวิทยาลัย เรื่อง ข้อปฏิบัติในการสอบของนิสิต พ.ศ. 2564
3. นิสิตที่มาสายหรือขาดเรียนต้องติดตามเนื้อหาการเรียน การนัดสอบ หรือประกาศต่าง ๆ เอง จะอ้างว่ามาสายหรือขาดเรียนเป็นเหตุผลว่าไม่ทราบไม่ได้
4. นิสิตต้องส่งชิ้นงานตามวันและเวลาที่กำหนดเท่านั้น หากไม่ส่งตามกำหนดไม่ว่าด้วยเหตุผลใด จะได้รับคะแนน 0 ในส่วนของงานชิ้นนั้น
5. นิสิตต้องทำงานทุกชิ้นเอง หากมีการลอกงานคนอื่น ไม่ว่าในรูปแบบใด จะได้ 0 ทุกคนทุกกรณี

<Callout type="warn" title="สองข้อที่ไม่มีข้อยกเว้น">
ส่งงานช้า ได้ 0 ในงานชิ้นนั้น และลอกงาน ได้ 0 ทุกคนที่เกี่ยวข้อง ทั้งสองข้อเขียนไว้แบบไม่มีเงื่อนไขผ่อนผัน
</Callout>

## ความซื่อสัตย์ทางวิชาการ

สไลด์ Administrivia ยกตารางของ MIT มาอธิบายว่าอะไรนับเป็นการทุจริต แบ่งเป็น 4 กลุ่ม

- **Plagiarism** — อย่าซื้อรายงานหรือให้คนอื่นเขียนแทน อย่าลอกไอเดีย ข้อมูล หรือถ้อยคำโดยไม่อ้างอิงแหล่งที่มา
- **Unauthorized Collaboration** — อย่าทำงานร่วมกับเพื่อนเกินขอบเขตที่อาจารย์อนุญาตไว้
- **Cheating** — อย่าลอกคำตอบเพื่อน อย่าให้เพื่อนทำงานแทน อย่าสร้างผลลัพธ์ปลอม อย่าใช้อุปกรณ์อิเล็กทรอนิกส์ระหว่างสอบ อย่าแก้ข้อสอบที่ตรวจแล้วส่งขอตรวจใหม่ และอย่าส่งงานที่เคยส่งในวิชาอื่นมาแล้ว
- **Facilitating Academic Dishonesty** — อย่าให้เพื่อนลอกคำตอบของเรา และอย่าสอบหรือทำงานแทนเพื่อน

**ควรทำ** — อ้างอิงและให้เครดิตเจ้าของงานที่เราหยิบมาใช้ ทำงานขึ้นใหม่สำหรับทุกวิชา และรับคำแก้จากอาจารย์ในฐานะส่วนหนึ่งของการเรียนรู้

สไลด์อ้างอิงคู่มือของ MIT ที่ [integrity.mit.edu](https://integrity.mit.edu/handbook/academic-integrity-mit/what-academic-integrity)
